What's inside

This is the guide to the system in the screenshots: 41 specialised agents running 377 scheduled jobs across 10 free providers, on one Mac. Not a theory of how you might build one.

14 pages, six sections:

  • What it does right now — the actual jobs the system performs daily, so you know what you are building toward.
  • The architecture — the core concept, the stack layer by layer, the free providers, the routing logic that picks a model per task, and the exact.env to create.
  • Agent structure — all 41 agents — the full directory with each agent's role, the IDENTITY.md system that defines them, and how memory and skills attach.
  • The cron system — the commands you will actually use, and how jobs are grouped so they do not all fire at once.
  • The bridge architecture — how the pieces talk, and the key files to know.
  • Getting started checklist — install, keys, Chrome bridge, then editing each identity for your own niche.

What this is not: a hosted product, a course, or a one-click installer. You will be editing config files and reading logs. If that sounds like work rather than a hobby, this is the wrong purchase.

On the numbers: the agent and job counts in this guide are generated from the running system each time it is built, not typed in. If you see 41 agents on this page, the guide says 41 too.
